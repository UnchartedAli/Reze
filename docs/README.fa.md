# REZE 3.0 — سیستم‌عامل دیجیتال شخصی شما

ریز (Reze) یک **یوزربات تلگرام** خودمیزبان است که با حساب شخصی خودتان کار
می‌کند: موتور پیام ASCII، استودیوی رسانه، دروازه‌ی چندمدلی هوش مصنوعی، حافظه‌ی
ماندگار، ابزارهای دانش شخصی، ذخیره‌سازی رمزنگاری‌شده، موتور گردش‌کار،
یکپارچه‌سازی‌های اختیاری و یک پنل وب بدون جاوااسکریپت. یک فرآیند پایتون و یک
فایل SQLite.

نسخه **3.0.0** · سازنده **UnchartedAli** · کانال [@yamods](https://t.me/yamods) · مجوز MIT

> **مهم:** ریز با حساب تلگرام **شما** کار می‌کند. فقط روی حسابی اجرا کنید که
> مالک آن هستید. رشته‌ی نشست (session)، هش API و کلید Vault مثل رمز عبور هستند.

## نصب سریع

پیش‌نیازها:

| مورد | توضیح |
| --- | --- |
| پایتون | نسخه 3.11 یا بالاتر |
| تلگرام | `api_id` و `api_hash` از https://my.telegram.org |
| شناسه عددی حساب | برای `REZE_OWNER_ID`؛ فقط این حساب می‌تواند دستور بدهد |
| FFmpeg | اختیاری؛ برای تبدیل ویدیو و صدا |

```bash
python -m venv .venv
# ویندوز: .venv\Scripts\activate
# لینوکس/مک: source .venv/bin/activate
pip install -r requirements.txt

python -m reze.installer
```

نصب‌کننده‌ی گرافیکی ترمینال هشت مرحله دارد: بررسی سیستم، اطلاعات تلگرام،
هوش مصنوعی (اختیاری)، زبان، مسیر داده، ربات همراه (اختیاری)، مرور نهایی و
ساخت پایگاه داده. همه‌ی رمزها هنگام تایپ پنهان می‌شوند، ورودی‌ها اعتبارسنجی
می‌شوند و فایل `.env` موجود بدون تأیید شما بازنویسی نمی‌شود (ابتدا یک نسخه‌ی
پشتیبان با تاریخ ساخته می‌شود). Ctrl+C بدون خطا خارج می‌شود.

اگر نصب‌کننده را نمی‌خواهید:

```bash
cp .env.example .env
# مقادیر REZE_API_ID، REZE_API_HASH، REZE_OWNER_ID،
# REZE_PANEL_PASSWORD_HASH، REZE_SECRET_KEY و REZE_VAULT_KEY را پر کنید
python scripts/generate_session.py
# رشته‌ی چاپ‌شده را در REZE_SESSION_STRING بگذارید
python -m reze.app
```

راهنمای کامل نصب (Docker، systemd، سرور ابری): [INSTALLATION.md](INSTALLATION.md)
و [DEPLOY.md](../DEPLOY.md).

## اولین اجرا

1. برنامه بنر، آدرس پنل (پیش‌فرض `http://127.0.0.1:8080`) و آدرس سلامت را
   چاپ می‌کند.
2. در پنل وارد شوید.
3. از هر چتی به حساب خودتان `.alive`، `.status` و `.diagnostics` بفرستید.
4. `.features` را بفرستید: همه‌ی کلیدها **خاموش** هستند.
5. `.help` را بفرستید؛ برای هر دستور، `.help <command>` راهنما و مثال می‌دهد.

در اولین اجرا پایگاه داده تا نسخه‌ی **v4** مهاجرت می‌کند. پایگاه داده‌ی نسخه
2.x در همان‌جا به‌روزرسانی می‌شود و تنظیمات قبلی حفظ می‌شوند.

## قابلیت‌های اختیاری: همه خاموش

**هیچ قابلیت اختیاری‌ای به‌طور خودکار روشن نمی‌شود** — نه با نصب، نه با
مهاجرت، نه با ری‌استارت و نه با بازنشانی تنظیمات. روشن‌کردن یک قابلیت هرگز
قابلیت دیگری را روشن نمی‌کند. قابلیت‌های حساس نیاز به کلمه‌ی `confirm` دارند.

```text
.features                       فهرست ۲۳ کلید و وضعیت آن‌ها
.features status vault          وضعیت یک کلید
.features enable memory         روشن‌کردن حافظه
.features enable vault confirm  روشن‌کردن گاو‌صندوق با تأیید صریح
.features disable vault         خاموش‌کردن
```

| کلید | کار | حساس |
| --- | --- | --- |
| `memory` | حافظه‌ی ماندگار برای هوش مصنوعی | خیر |
| `life_graph` | گراف افراد، پروژه‌ها، مکان‌ها و موضوعات | خیر |
| `crm` | مخاطبین، تاریخ تعامل، تولدها | خیر |
| `decisions` | دفتر تصمیم‌ها و بازبینی نتیجه | خیر |
| `focus` | جلسات تمرکز زمان‌دار | خیر |
| `timeline` | خط زمانی رویدادها | خیر |
| `writing_dna` | نمونه‌های نوشتار و تحلیل سبک | خیر |
| `projects` | پروژه‌ها و کارها | خیر |
| `expenses` | ثبت هزینه و خلاصه‌ی ماهانه | خیر |
| `workflows` | گردش‌کارهای ماندگار چندمرحله‌ای | بله |
| `random_reactions` | واکنش‌های نادر در چت‌های انتخابی | بله |
| `background_monitoring` | پایش پس‌زمینه | بله |
| `vault` | گاو‌صندوق رمزنگاری‌شده | بله |
| `security_sentinel` | بررسی‌های امنیتی محلی | بله |
| `self_maintenance` | سلامت پایگاه داده و نگهداری | خیر |
| `bot_companion` | ربات تلگرام همراه، فقط برای مالک | بله |
| `ai_agent` | فراخوانی ابزار با تأیید کد | بله |
| `model_council` | پرسش از چند مدل و جمع‌بندی | بله |
| `insights` | آمار هفتگی محلی | خیر |
| `smart_inbox` | دسته‌بندی محلی پیام‌های ورودی | بله |

| `voice_intelligence` | رونویسی پیام صوتی | بله |
| `document_intelligence` | استخراج متن از سند | بله |

## زبان فارسی

```text
.language fa     تغییر رابط به فارسی
.language en     بازگشت به انگلیسی
```

- متن رابط، برچسب‌های راهنما، نام قابلیت‌ها، منوی پنل و صفحه‌ی ورود به فارسی
  ترجمه می‌شوند. متن بدنه‌ی صفحه‌های پنل در نسخه 3.0 انگلیسی است.
- ورودی فارسی نرمال می‌شود: `ي/ی`، `ك/ک`، اعداد عربی و فارسی، اعراب،
  نشانه‌های جهت و فاصله‌های اضافی. نیم‌فاصله حفظ می‌شود.
- پاسخ‌های فارسی با نشانه‌ی راست‌به‌چپ ارسال می‌شوند.
- تاریخ‌ها به‌صورت ISO-8601 ذخیره می‌شوند و در صورت نیاز با تقویم جلالی
  نمایش داده می‌شوند.
- نام و نحو دستورها در هر دو زبان یکسان است.

جزئیات: [LOCALIZATION.md](LOCALIZATION.md).

## راه‌اندازی هوش مصنوعی

```ini
REZE_AI_PROVIDER=openai          # openai | anthropic | gemini | openai_compatible
REZE_AI_MODEL=gpt-4o-mini
REZE_AI_API_KEY=sk-...
```

سپس `.ai`، `.summarize`، `.translate`، `.rewrite`، `.digest` و `.describe`
کار می‌کنند. بدون کلید، دستورها صریحاً می‌گویند که هوش مصنوعی تنظیم نشده است
و هیچ پاسخ جعلی نمی‌سازند.

فراخوانی ابزار توسط مدل (`.agent`) یک قابلیت حساس و جداست: فهرست بسته‌ی
ابزارها، کد تأیید ۶ رقمی با اعتبار ۱۵ دقیقه، سقف روزانه و ثبت کامل در
`ai_tool_audit`. جزئیات: [AI.md](AI.md).

## امنیت و حریم خصوصی

- ربات فقط به **حساب مالک** پاسخ می‌دهد؛ غریبه‌ها هیچ پاسخی نمی‌گیرند.
- رمزها، رشته‌ی نشست و کلید Vault هرگز در لاگ یا پنل نمایش داده نمی‌شوند.
- ورودی‌های Vault با AES-256-GCM رمز می‌شوند و کلید با scrypt مشتق می‌شود.
  اگر `REZE_VAULT_KEY` را گم کنید، داده‌های Vault قابل بازیابی نیستند.
- پشتیبان‌گیری با API آنلاین SQLite انجام می‌شود، قابل بررسی است و
  بازیابی نیاز به کد تأیید ۶ رقمی دارد.
- پنل: کوکی `HttpOnly`، توکن CSRF برای هر POST، CSP سخت‌گیرانه، محدودیت
  اندازه‌ی بدنه و بدون جاوااسکریپت.
- `.exec` به‌طور پیش‌فرض خاموش است. `.broadcast` کد تأیید و سقف دارد.
- Message Guard پیام‌های دیگران را روی همین دستگاه ذخیره می‌کند؛ در گروه‌های
  مشترک به افراد اطلاع بدهید و `.watch ttl` را فقط جایی استفاده کنید که
  پذیرفتنی است.

## پرسش‌های رایج

| مشکل | راه‌حل |
| --- | --- |
| پیام «API_ID / API_HASH missing» | هر دو مقدار را در `.env` پر کنید؛ تا آن زمان کلاینت تلگرام خاموش است. |
| ورود به پنل رد می‌شود | دقیقاً یکی از `REZE_PANEL_PASSWORD` یا `REZE_PANEL_PASSWORD_HASH` را تنظیم کنید. |
| دستور می‌گوید قابلیت خاموش است | این حالت پیش‌فرض است؛ دستور `.features enable <key>` را اجرا کنید (برای حساس‌ها با `confirm`). |
| Vault بعد از تغییر سرور باز نمی‌شود | `REZE_VAULT_KEY` عوض شده یا وجود ندارد. |
| دستورهای ویدیو اجرا نمی‌شوند | FFmpeg نصب نیست؛ نصب کنید یا `REZE_FFMPEG_PATH` را تنظیم کنید. |
| هوش مصنوعی «تنظیم نشده» می‌دهد | ارائه‌دهنده، مدل و کلید را تنظیم کنید و `.diagnostics` را ببینید. |
| برچسب واقعی به‌صورت فایل می‌آید | برای برچسب واقعی `REZE_STICKER_BOT_TOKEN` لازم است. |

## دامنه‌ی پروژه

REZE یک ابزار شخصی است و **هیچ قابلیت تبلیغات، ارسال انبوه پیام ناخواسته،
جمع‌آوری اعضای گروه یا کمپین تبلیغاتی ندارد**. اتوماسیونی که اسپم کند می‌تواند
باعث محدودشدن یا مسدودشدن حساب در تلگرام شود؛ `.tagall`، ارسال همگانی،
واکنش‌ها و گردش‌کارها را محافظه‌کارانه نگه دارید.

ریز پروژه‌ای مستقل است و وابسته به تلگرام نیست.
